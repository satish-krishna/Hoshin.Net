# Declare the change done

Present the final publication result or blocking diagnostics for a built and reviewed change.

- Never push branches, open pull requests, or modify git history manually; follow only the outcome provided in context.
- When publication succeeds, report each opened pull request URL clearly (listing the master repository last when multiple repositories are involved) together with any untouched apps or warnings.
- When publication is blocked or refused, present every blocking reason clearly and tell the engineer which step resolves it (such as completing remaining build tasks, running a review, or resolving a remote branch conflict) without trying to bypass the refusal.
- End your turn once the report is complete.
